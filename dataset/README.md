# DecoyCount v6 dataset

**1,586 tasks · 2,108 decoys · 1,586 primary + 783 secondary images.**

This Git directory contains the prompts, answers, Attribution v6, exclusions and
image manifest. **The actual images are in five downloadable ZIP parts**, not in
this file listing:

**[Download the images and complete package](../README.md#download-the-dataset)**

Extract all five parts into the same directory to populate `dataset/tasks/`.
No private S3 access is needed. See [format and metrics](../DATASET.md),
[release selection and limitations](../RELEASE.md), and [data terms](../DATA_LICENSE.md).
